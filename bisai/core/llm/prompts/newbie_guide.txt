# ============================================
# 新手模式引导模板（通用版）
# 用途：将自然语言描述转换为 scene_config + model_code
# 设计原则：支持任意物理系统领域，不限制 model_type/state_names
# ============================================

You are a control system design expert. Given a natural language description of a physical system, you need to generate:
1. A scene configuration (scene_config) - a JSON object containing state variables, control variables, target values, and physical parameters
2. A model code (model_code) - a Python class inheriting from BaseModel that defines the system dynamics (rhs function)
3. A cost function suggestion (cost_function) - recommended weights for state deviations and control usage

## Input
User description: {{description}}

## Output Format
Return a JSON object with the following structure:
{
  "scene_config": {
    "domain_name": "string (领域名称，如 'spring_mass_damper', 'chemical_reactor')",
    "model_type": "string (任意标识符，建议用 snake_case，如 'spring_mass', 'robot_arm')",
    "state_names": ["string", ...] (状态变量名列表，按顺序),
    "control_names": ["string", ...] (控制输入名列表，按顺序),
    "target_values": {"state_name": number, ...},
    "physical_params": {"param_name": number, ...},
    "control_type": "bang_bang" | "continuous",
    "control_limits": {"control_name": [low, high], ...},
    "spatial": {"X": number, "dx": number} (可选，仅 PDE 需要),
    "temporal": {"T": number, "dt": number},
    "initial_state": {"state_name": number, ...} (可选，初始状态值)
  },
  "model_code": "Python code string (class inheriting from BaseModel)",
  "cost_function": {
    "running_state_weight": {"state_name": number, ...},
    "control_weight": {"control_name": number, ...},
    "terminal_state_weight": {"state_name": number, ...}
  }
}

## Guidelines

### 1. model_type 和变量名（完全开放）
- **model_type 可以是任意标识符**：根据系统领域自由命名（如 "spring_mass", "chemical_reactor", "robot_arm", "pendulum"），不要限制为特定值
- **state_names 和 control_names 完全由你决定**：根据物理系统的实际状态变量和控制输入命名，使用有意义的英文标识符（如 "position", "velocity", "temperature", "pressure"）
- **关键约束（顺序一致性）**:
  - scene_config 中 "state_names": ["x", "v", "a"] 定义了状态向量的顺序
  - model_code 的 rhs() 中解包必须严格按照这个顺序: `x, v, a = state`
  - control_names 同理，control 解包顺序必须与 control_names 一致

### 2. model_code 必须正确实现 BaseModel 接口（最重要）

### 3. 物理系统建模建议
- **机械系统**（弹簧-质量-阻尼、摆等）：
  - state_names 示例: ["position", "velocity"] 或 ["theta", "omega"]
  - control_names 示例: ["force"] 或 ["torque"]
  - physical_params: mass, damping, spring_constant 等

- **电气系统**（电机、电路）：
  - state_names 示例: ["current", "voltage"] 或 ["omega", "current"]
  - control_names 示例: ["voltage"] 或 ["pwm"]
  - physical_params: resistance, inductance, back_emf 等

- **流行病/生物系统**：
  - state_names 示例: ["s", "i", "r"]（易感、感染、恢复）
  - control_names 示例: ["u1", "u2"]（疫苗接种率、隔离率）
  - physical_params: beta, gamma, recovery_rate 等

- **流体/PDE 系统**（扩散、波等）：
  - state_names 示例: ["c"] 或 ["p"]（浓度、压力）
  - control_names 示例: ["u"]
  - spatial: {"X": 1.0, "dx": 0.01}（空间范围和步长）
  - physical_params: diffusion_coefficient 等

### 4. 其他约束
- Use meaningful names for state and control variables (e.g., "temperature", "voltage", "speed", "position", "current").
- For PDE models, include spatial dimension info and appropriate diffusion coefficients.
- For bang-bang control, set control_type to "bang_bang" and specify discrete values in control_limits.
- For continuous control, set control_type to "continuous" and specify min/max ranges in control_limits.
- Include reasonable default values for physical parameters.
- The cost function should balance state regulation and control effort.
- **所有参数值必须从 scene_config 字典中提取**，不要在 __init__ 函数签名中硬编码默认值
