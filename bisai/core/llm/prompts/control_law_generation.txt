## 控制类型指南

根据 `scene_config["control_type"]` 选择：

### bang_bang（离散控制）
```python
# 示例：阈值触发 bang-bang
u1 = np.where(I > params.get("threshold_I", 1.0), 1.0, 0.0)
u2 = np.where(S > params.get("threshold_S", 500.0), 0.5, 0.0)
return np.array([u1, u2])
```

### continuous（连续控制）
```python
# 示例：比例反馈 + 饱和
error = state[0] - params.get("target", 1.0)
u = np.clip(params.get("gain", 1.0) * error, -1.0, 1.0)
return np.array([u])
```

## Few-Shot 示例

### 示例 1: SIR 流行病模型（bang_bang）

**输入片段**:
```json
{
  "state_names": ["S", "I", "R", "Q"],
  "control_names": ["u1", "u2"],
  "control_type": "bang_bang",
  "target_values": {"I": 50.0}
}
```

**输出示例**:
```python
# ========== VECTORIZATION SELF-CHECK ==========
# [ ] 1. No `float(`, `int(`, `bool(` on arrays...
# [ ] 2. `np.where` uses `&` / `|`, NOT `and` / `or`.
# [ ] 3. `np.max` / `np.min` / `np.abs` used.
# [ ] 4. No `for i in range(M+1)` loops.
# [ ] 5. Return shape correct.
# [ ] 6. All controls implemented.
# [ ] 7. Time normalization correct.
# ==============================================

# ========== PARAM DECLARATION ==========
# @param: threshold_I (1.0, 100.0)
# @param: threshold_S (100.0, 1000.0)
# ========== END PARAM DECLARATION ==========

import numpy as np

def control_law(t, x, state, params):
    """
    SIR epidemic bang-bang control.
    """
    S, I, R, Q = state

    # Thresholds from params
    th_I = params.get("threshold_I", 50.0)
    th_S = params.get("threshold_S", 800.0)

    # Bang-bang: isolate if S high, treat if I high
    u1 = np.where(S > th_S, 1.0, 0.0)  # isolation
    u2 = np.where(I > th_I, 1.0, 0.0)  # treatment

    return np.array([u1, u2])
```

## 向量化安全规则（简版）

**【必须遵守，否则代码会崩溃】**

| 规则 | ❌ 错误 | ✅ 正确 |
|------|---------|---------|
| 数组类型转换 | `float(arr > 0)` | `(arr > 0).astype(float)` |
| 逻辑运算 | `np.where(a and b, 1, 0)` | `np.where(a & b, 1, 0)` |
| 聚合函数 | `max(arr)` | `np.max(arr)` |
| 空间循环 | `for i in range(M): ...` | `np.where(cond, val, 0)` |
